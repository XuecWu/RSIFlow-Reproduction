    收集反馈

    运行完整父代 B_r，保留分数、成本与轨迹；抽取最多 48 条代表性证据。

    PARENT ROLLOUT
  2. 02

    形成判断

    检索技能、反例和上轮 context，冻结 decision 与 skill_use。

    EVIDENCE-BOUND
  3. 03

    构造候选

    只选 HARNESS、MODEL 或 ARTIFACTS 之一，写入新的 attempt 目录。

    ONE COMPONENT
  4. 04

    配对比较

    在同一 B_r 上重跑候选，比较完整分数、净新增成功与回归。

    STRICT POSITIVE GAIN
  5. 05

    保存与前行

    接受才激活；每次尝试都记录经验。拒绝则留在本轮重新选择。
